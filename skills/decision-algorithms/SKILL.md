# 系统性决策能力提升工作环境

> 好的决策，后面对应的是好的可能性，也就是好的概率。而好运，就是穿着世俗外衣的概率。
> 这个 Skill 帮你建立EKB决策算法框架，掌握在不确定性中做出明智决策的方法论。

## 1. 核心定位

**不是什么**：不是成功学鸡汤，不是短期投机技巧，不是 guarantee 结果的魔法。

**是什么**：一个基于概率论、博弈论和行为经济学的系统化决策工作环境，提供可复制的决策算法框架和思维模型。

**解决什么问题**：
- 重大决策时犹豫不决、事后后悔
- 凭直觉做决策，缺乏系统性方法
- 不知道如何在不确定性中分配资源
- 想提升决策质量但找不到可操作的路径
- 面对复杂选择时陷入分析瘫痪

## 3. 核心概念

### 3.1 好决策的定义

**核心公式**：
```
好决策 = 围绕目标 × 面向不确定性 × 分配资源 × 实现人生持续向好概率最大化
```

**三个要点**：
1. 决策目标是未来持续向好，需要衡量收益和风险
2. 决策需要投入本钱和资源，需要科学计算投入比例
3. 决策总是条件不足的，需要边瞄准边射击，持续迭代

**决策与运气的辩证关系**：
- 好决策通常和运气有关
- 好的决策又和好的运气互为因果
- 好的决策=停留在有优势的领域+尊重常识+情绪稳定

### 3.2 EKB决策算法框架

**EKB = Expected Value + Kelly Criterion + Bayes' Theorem**

#### 第一层：期望值（Expected Value）- 骆驼

**象征**：骆驼象征着决策的理性和责任

**核心问题**：这个决策的期望收益是多少？

**公式**：
```
期望值 = (成功概率 × 成功收益) - (失败概率 × 失败损失)
```

**应用原则**：
- 选择期望值为正且最高的选项
- 不只是看概率，更要看收益风险比
- 长期重复正期望值决策，好运自然来

#### 第二层：凯利公式（Kelly Criterion）- 狮子

**象征**：狮子象征着决策的勇敢和智慧

**核心问题**：我应该投入多少资源？

**公式**：
```
最优下注比例 = (期望收益 - 失败损失) / (成功收益 - 失败损失)
```

**简化版**：
```
f* = (p × b - q) / b
其中：p=胜率，q=败率(1-p)，b=赔率
```

**应用原则**：
- 不要all in，也不要过于保守
- 根据胜率和赔率动态调整投入比例
- 即使是最优决策，也要控制单次投入不超过总资源的20%

#### 第三层：贝叶斯定律（Bayes' Theorem）- 婴儿

**象征**：婴儿象征着决策的初心和成长

**核心问题**：如何根据新信息持续优化决策？

**公式**：
```
后验概率 = (似然度 × 先验概率) / 证据
```

**应用原则**：
- 保持开放，根据新信息调整判断
- 不要固守最初的决策
- 边瞄准边射击，持续迭代优化

### 3.3 连环7问法

判断一个决策是否是好决策，问自己这7个问题：

| 序号 | 问题 | 核心要点 |
|------|------|----------|
| 1 | 我知道自己到底想要什么吗？ | 对自己诚实，不要为别人活 |
| 2 | 我是在打自己最有希望打赢的仗吗？ | 找快速向上的电梯，不要在悬崖攀岩 |
| 3 | 我愿意为这个决策投入稀缺的筹码吗？ | 时间、精力、专注、金钱，以及机会成本 |
| 4 | 我知道自己不能失去什么吗？ | 承受万一失败的后果，不要失去不能失去的东西 |
| 5 | 我有"撤退路线图"吗？ | 永远有Plan B，不要让自己失去选择权 |
| 6 | 我如何在一个动态的过程中不断优化决策？ | 好决策是一步步优化逼近的，不是一蹴而就 |
| 7 | 我的这个决策会让我变成一个更好的人吗？ | 好的人做出好决策，好决策塑造好的人 |

### 3.4 二阶理性

**一阶理性 vs 二阶理性**：

| 维度 | 一阶理性 | 二阶理性 |
|------|----------|----------|
| **核心** | 努力 | 选择 |
| **问题** | 我如何获得优势打赢他？ | 我一定要和他打吗？ |
| **思维** | 杀伐决断、强化自身 | 战略选择、放弃不必要战斗 |
| **难度** | 很难（需要顶级能力） | 相对容易（需要清醒认知） |

**核心洞察**：
- 大多数人的精力放在"努力"上，但"选择"比"努力"更重要
- 不要在错误的赛道上拼命奔跑
- 学会说"不"，比学会说"是"更有价值

### 3.5 决策陷阱识别

**12个常见决策陷阱**：

| 陷阱 | 核心表现 | 规避方法 |
|------|----------|----------|
| **老好人陷阱** | 不懂拒绝，讨好他人 | 建立边界，学会说"不" |
| **占便宜陷阱** | 贪婪，只看眼前利益 | 大局观，考虑长期价值 |
| **内耗陷阱** | 反复纠结，无法决策 | 设定决策截止时间 |
| **惯性陷阱** | 被习惯和路径依赖束缚 | 定期审视，打破常规 |
| **委托陷阱** | 过度信任他人委托 | 建立监督机制，分散风险 |
| **确定性陷阱** | 追求100%确定性而错失机会 | 接受适度不确定性 |
| **操控陷阱** | 被他人设计的轨道操控 | 独立思考，识别利益关系 |
| **成功陷阱** | 过去的成功成为包袱 | 持续学习，拥抱变化 |
| **AI陷阱** | 过度依赖AI决策 | 保持决策主导权 |
| **永恒轮回陷阱** | 重复相同模式 | 复盘迭代，跳出循环 |
| **自由意志陷阱** | 误以为自己有完全选择权 | 理解约束条件 |
| **贪嗔痴陷阱** | 情绪化决策 | 情绪管理，延迟决策 |

### 3.6 关键思维模型

**宽框架 vs 窄框架**：
- 窄框架：只看单次决策的得失
- 宽框架：看一系列相关决策的整体优化
- 赚大钱需要宽框架思维

**对冲思维**：
- 做错决策时如何还能赢
- 永远有Plan B
- 不要把所有筹码放在一个选项上

**机会成本思维**：
- 每个决策都有隐性成本
- 问自己：我愿意失去别的选项吗？

**复利思维**：
- 正确使用复利公式：本金×(1+收益率)^时间
- 关键是：持续正向的决策+足够长的时间

## 4. 标准流程

### 4.1 EKB决策算法应用流程

```
Step 1: 期望值分析（骆驼层）
  ├─ 列出所有可行选项
  ├─ 估算每个选项的成功概率和失败概率
  ├─ 估算成功收益和失败损失
  ├─ 计算每个选项的期望值
  └─ 筛选期望值为正且最高的选项

Step 2: 凯利公式计算（狮子层）
  ├─ 确定最优下注比例
  ├─ 评估自身资源总量
  ├─ 计算单次决策最大投入（不超过总资源的20%）
  ├─ 分阶段投入（不要一把梭哈）
  └─ 设置止损线

Step 3: 贝叶斯迭代（婴儿层）
  ├─ 建立先验概率
  ├─ 设定信息收集计划
  ├─ 执行决策并收集反馈
  ├─ 根据新信息更新概率
  ├─ 调整后续决策
  └─ 持续优化
```

### 4.2 连环7问决策验证流程

```
Step 1: 目标澄清
  └─ 我真的知道我要什么吗？还是别人的期待？

Step 2: 战场评估
  └─ 这是我有优势的领域吗？胜率如何？

Step 3: 资源评估
  └─ 我愿意投入什么？机会成本是什么？

Step 4: 风险底线
  └─ 最坏情况是什么？我能承受吗？

Step 5: 退出机制
  └─ 什么时候撤退？Plan B是什么？

Step 6: 迭代计划
  └─ 如何根据新信息调整？

Step 7: 自我成长
  └─ 这个决策会让我变成更好的人吗？
```

### 4.3 重大决策工作流

```
Phase 1: 问题界定（1-2天）
  ├─ 明确决策目标和约束条件
  ├─ 收集基础信息
  └─ 识别决策类型（一次性/可逆/迭代式）

Phase 2: 选项生成（2-3天）
  ├─ 头脑风暴所有可能选项
  ├─ 初步筛选（排除明显不合理选项）
  └─ 保留3-5个候选方案

Phase 3: 深度分析（3-5天）
  ├─ 期望值分析：每个选项的EV计算
  ├─ 敏感性分析：关键变量变化的影响
  ├─ 情景分析：最好/最可能/最坏情况
  └─ 风险评估：失败后果和应对预案

Phase 4: 决策制定（1天）
  ├─ 应用连环7问验证
  ├─ 凯利公式计算投入比例
  ├─ 制定执行计划和检查点
  └─ 做出决策并记录理由

Phase 5: 执行与迭代（持续）
  ├─ 按计划执行
  ├─ 定期收集反馈（每周/每月）
  ├─ 贝叶斯更新：调整概率和策略
  └─ 复盘总结：记录决策过程和结果
```

### 4.4 常见场景决策框架

**职业决策框架**：
```
1. 行业趋势：这个行业是在上升期还是衰退期？
2. 公司前景：公司是增长还是停滞？
3. 岗位价值：这个岗位能积累可迁移能力吗？
4. 团队质量：同事和领导是否优秀？
5. 个人匹配：兴趣+能力+价值的交集？
```

**投资决策框架**：
```
1. 期望值：正期望值还是负期望值？
2. 凯利比例：应该投入多少？
3. 对冲：是否需要对冲？
4. 周期：现在在周期的什么位置？
5. 退出：什么时候退出？
```

**创业决策框架**：
```
1. 问题真实性：是真问题还是伪需求？
2. 市场规模：天花板有多高？
3. 竞争格局：对手有多强？
4. 自身优势：为什么是我们？
5. 最小验证：如何低成本验证？
```

## 5. 场景脚本

### 场景1：是否应该辞职创业？

**背景**：用户在一家大厂工作5年，年薪50万，现在有一个创业想法，犹豫是否辞职。

**脚本**：
```
AI（决策算法助手）：

【第一步：期望值分析】
选项A：继续工作
  - 成功概率：高（80%继续平稳发展）
  - 收益：年薪50万+，稳定，福利好
  - 损失：机会成本（创业可能的收益）
  - EV = 50万 × 0.8 = 40万

选项B：辞职创业
  - 成功概率：中低（10-20%存活率）
  - 收益：如果成功，年入200万+
  - 损失：0收入+投入成本50万
  - EV = (200万 × 0.15) - (50万 × 0.85) = 30万 - 42.5万 = -12.5万

【初步判断】从期望值看，继续工作更高。

【第二步：凯利公式】
如果坚持创业：
  - 胜率p = 15%，败率q = 85%
  - 赔率b = (200-50)/50 = 3
  - f* = (0.15×3 - 0.85) / 3 = (0.45 - 0.85) / 3 = -0.13
  - 凯利公式为负，说明不应该全押

【第三步：二阶理性】
问：我一定要现在辞职创业吗？
- 能不能先副业验证？
- 能不能等积累更多资源后再创业？
- 有没有更稳妥的方式测试这个想法？

【连环7问验证】
1. 我真正想要的是什么？（财务自由/自我实现/社会影响力）
2. 这是我的优势领域吗？（行业经验、人脉、技能）
3. 我愿意投入多少？（时间、金钱、机会成本）
4. 最坏情况我能承受吗？（积蓄能支撑多久？）
5. 撤退路线是什么？（失败后能回去吗？）
6. 如何迭代优化？（MVP测试、快速迭代）
7. 这会让我变成更好的人吗？（成长、学习、贡献）

【建议】
1. 不要裸辞，先用副业验证（6个月）
2. 最小可行产品测试市场需求
3. 积累至少6-12个月的生活费
4. 设定明确的验证指标和止损线
5. 如果副业收入超过主业50%，再考虑全职
```

### 场景2：买房还是继续租房？

**背景**：用户手头有100万首付，纠结是买房还是继续租房投资。

**脚本**：
```
AI（决策算法助手）：

【第一步：期望值分析】

选项A：买房（总价300万，贷款200万）
  - 成功概率：房价上涨概率60%
  - 收益：房价上涨20% = 60万
  - 损失：房贷利息+税费+机会成本 = 约100万
  - 3年EV = (60万 × 0.6) - (100万 × 0.4) = 36万 - 40万 = -4万

选项B：继续租房，资金投资
  - 成功概率：投资收益概率70%
  - 收益：100万投资3年，按年化8% = 26万
  - 损失：租金支出3年 = 12万
  - 3年EV = (26万 × 0.7) - (12万 × 0.3) = 18.2万 - 3.6万 = 14.6万

【初步判断】从期望值看，租房投资更高。

【第二步：考虑非货币因素】
- 买房：稳定性、子女教育、心理安全感（难以量化）
- 租房：灵活性、资金流动性、投资自主权

【连环7问验证】
1. 我真正想要的是什么？（家/资产增值/自由）
2. 这是我的优势领域吗？（懂房市吗？懂投资吗？）
3. 我愿意投入多少？（30年月供压力）
4. 最坏情况我能承受吗？（房价下跌30%？失业断供？）
5. 撤退路线是什么？（卖房/转租？）
6. 如何优化？（如果买，买哪里？如果租，投什么？）
7. 这会让我变成更好的人吗？（负债压力 vs 投资能力）

【建议】
1. 如果自住需求强，买小不买大，控制负债
2. 如果投资需求强，租房+指数基金更优
3. 不要为了投资而买房（租售比不合理）
4. 考虑城市能级：一线城市核心区可买，三四线谨慎
```

### 场景3：选择哪个工作offer？

**背景**：用户拿到两个offer，A公司大厂稳定但成长慢，B公司创业公司不稳定但成长快。

**脚本**：
```
AI（决策算法助手）：

【期望值对比】

Offer A：大厂（年薪40万，稳定）
  - 成长概率：80%有机会晋升
  - 晋升收益：3年后年薪60万+股票
  - 失败损失：技能提升慢，错过窗口期
  - 5年EV ≈ 250万

Offer B：创业公司（年薪35万+期权）
  - 成功概率：20%公司上市/被收购
  - 成功收益：期权价值200万+
  - 失败损失：公司倒闭，需要重新找工作
  - 5年EV ≈ (200万×0.2) + (180万×0.8) = 40+144 = 184万

【初步判断】大厂期望值更高。

【但考虑二阶理性】
问：我一定要二选一吗？
- 能不能先去大厂积累，再去创业公司？
- 能不能谈B公司更高的base？
- 能不能要更多信息再做决定？

【连环7问】
1. 5年后我想成为什么样的人？（专家/管理者/创业者）
2. 哪个选项更接近目标？（大厂背书 vs 创业经验）
3. 我愿意投入什么？（时间精力、机会成本）
4. 最坏情况是什么？（大厂裁员、创业公司倒闭）
5. 撤退路线？（大厂背景好跳槽、创业公司经验可迁移）
6. 如何迭代？（1-2年后评估，再调整）
7. 哪个让我成长更快？（取决于具体岗位和团队）

【建议】
1. 如果目标是"稳定晋升"：选A
2. 如果目标是"快速成长"：选B（但要求更高base）
3. 最优策略：先去A积累3年，再去B拿更高职位
4. 考虑贝叶斯：先收集更多信息（和两边团队深度交流）
```

### 场景4：AI时代，我的职业会被取代吗？

**背景**：用户担心AI会取代自己的工作，不知道该如何决策。

**脚本**：
```
AI（决策算法助手）：

【决策框架】

Step 1: 风险评估
  - 任务可标准化程度：高→高风险
  - 数据可获取性：高→高风险
  - 创意/复杂判断需求：低→高风险
  - 人际交互需求：低→高风险

Step 2: 期望值计算
选项A：维持现状
  - 被AI取代概率：30-50%（取决于职业）
  - 损失：失业、降薪、职业发展停滞
  - EV = 负期望（风险大于收益）

选项B：主动转型
  - 学习成本：时间+金钱投入
  - 转型成功率：60-70%
  - 收益：新技能+AI增强能力
  - EV = 正期望（投资自己）

Step 3: 凯利公式
  - 投入多少资源学习新技能？
  - 建议：总时间的20-30%用于学习
  - 不要all in学习，也不要完全不学习

Step 4: 二阶理性
  - 一定要和AI竞争吗？
  - 能不能成为会用AI的人？
  - 能不能找到AI+人类协作的新角色？

【连环7问】
1. 我核心价值是什么？（经验、判断、创造力、人际关系）
2. 哪些部分AI可以替代？（重复性、标准化任务）
3. 我如何增强不可替代性？（复杂决策、创新、人际）
4. 我愿意投入多少学习？（每天1小时 vs 脱产学习）
5. 最坏情况我能承受吗？（暂时降薪、转行阵痛）
6. 撤退路线？（保留现有技能作为backup）
7. 这会让我变成更好的人吗？（终身学习能力）

【建议】
1. 不要恐慌，但要重视
2. 识别自己工作中AI可替代的部分
3. 投资学习AI无法替代的技能（复杂判断、创造力、人际）
4. 成为会用AI的人，而不是被AI取代的人
5. 保持开放，准备转型
```

## 7. 关键技巧速查

### 期望值计算技巧
- **公式**：EV = (p × 收益) - ((1-p) × 损失)
- **原则**：只做正期望值决策
- **注意**：考虑隐性成本和机会成本

### 凯利公式应用技巧
- **公式**：f* = (p×b - q) / b
- **原则**：单次投入不超过总资源的20%
- **简化**：如果公式结果为负，不要参与

### 贝叶斯更新技巧
- **公式**：后验 = (似然 × 先验) / 证据
- **原则**：保持开放，持续更新
- **实践**：设定信息收集检查点

### 连环7问速查
- **目标**：我要什么？（不是别人要我什么）
- **战场**：我有优势吗？
- **筹码**：我愿意付出什么？
- **底线**：不能失去什么？
- **撤退**：Plan B是什么？
- **迭代**：如何优化？
- **成长**：我会变成更好的人吗？

### 二阶理性技巧
- **核心**：选择比努力更重要
- **方法**：先问"要不要做"，再问"怎么做"
- **练习**：每周记录一个"不做什么"的决策

## 8. 常见陷阱与规避

### 陷阱1：结果导向
- **表现**：因为结果好就觉得决策对，结果差就觉得决策错
- **规避**：评估决策质量看过程，不看结果

### 陷阱2：沉没成本
- **表现**：因为已经投入很多，不愿意放弃
- **规避**：只看未来的成本和收益，不看过去的投入

### 陷阱3：确认偏误
- **表现**：只找支持自己观点的信息
- **规避**：主动寻找反面证据， steelman opposing views

### 陷阱4：过度自信
- **表现**：高估自己的判断能力
- **规避**：保持概率思维，承认不确定性

### 陷阱5：分析瘫痪
- **表现**：过度分析，无法决策
- **规避**：设定决策截止时间，用"足够好"代替"完美"

### 陷阱6：从众心理
- **表现**：别人做什么我就做什么
- **规避**：独立思考，理解自己的独特情况

### 陷阱7：短期主义
- **表现**：只看短期收益，忽视长期价值
- **规避**：用宽框架思考，考虑一系列决策的整体

### 陷阱8：情绪化决策
- **表现**：愤怒、恐惧、贪婪时做决策
- **规避**：重大决策延迟24小时，情绪平复后再决定
