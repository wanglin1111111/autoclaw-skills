# SKILL.md - ai-native-gtm

## 任务边界

**做什么**：KOL/创作者合作框架、外联序列（冷邮件/LinkedIn）、社区与 launch 策略、GTM 阶段划分与指标。
**不做什么**：内容生产流水线、广告投放代运营、销售合同签署。
**红线**：外联与 KOL 合作必须满足目标国营销法规（CASL/GDPR/CAN-SPAM/FTC 披露）；禁止买名单、群发无退订、隐藏赞助。

## Gotchas 速查（详见 references/gotchas.md）

1. 加拿大 CASL 是严格 opt-in：未获明确同意就发 B2B 冷邮件，个人罚最高 100 万加元/次——比 CAN-SPAM 严一个量级
2. 美国 CAN-SPAM 最低要求：真实主题、识别发件人、每封含可用的 opt-out（10 天内生效）
3. FTC 16 CFR Part 255：KOL 免费产品也算物质关联，须披露；'给产品不算广告'是错觉
4. 自动抓取社交平台数据做外联清单违反平台 ToS（LinkedIn 明令禁止），账号封禁+法律风险
5. GDPR 下 B2B 邮箱也是个人数据，合法利益（legitimate interest）不是万能豁免，须做平衡测试并可拒收

> 科技产品营销不是流量游戏，而是信任转化。
> 传统营销工具依赖泛娱乐创作者或简单关键词匹配，导致垂直圈层用户无法听到核心声音。
> 这个 Skill 帮你设计 AI-Native 的科技产品 GTM 策略，精准匹配核心社群，将复杂硬核技术转化为信任故事。

> 与 `opc-startup` 和 `model-harness` 互补：
> - `opc-startup` 负责商业验证与资源对接
> - `model-harness` 负责技术执行与工程落地
> - `ai-native-gtm` 负责市场进入与增长策略

## 1. 任务边界

**做**
- 将科技产品定位转化为可执行的 GTM 策略
- 设计 AI 驱动的创作者/KOL 匹配与营销闭环
- 建立从内容审核到转化追踪的全链路框架
- 输出可复用的达人矩阵模型、内容策略、数据优化 SOP

**不做**
- 不代替用户执行真实的达人签约、付款、内容发布
- 不承诺“保证爆量”或“保证 ROI”；只提供验证过的策略框架
- 不处理与科技产品 GTM 无关的通用营销、品牌设计任务
- 不提供具体的达人联系方式或商务谈判

## 2. 核心概念速查

| 概念 | 含义 | 关键 Gotcha |
|------|------|-------------|
| AI-Native Marketing Agency | 以 AI 为核心驱动的营销服务机构 | 不是“用 AI 做营销”，而是“AI 原生设计整个营销链路” |
| Tech Creator GTM | 针对科技产品的创作者市场进入 | 科技博主能深度触达产品核心价值，转化率远高于泛娱乐创作者 |
| 达人金字塔模型 | 头部/腰部/尾部/KOC 分层矩阵 | 5% 头部做背书 + 20% 腰部做转化 + 75% 尾部做测试 |
| 黄金 3 秒 | 视频开篇的前 3 秒决定留存 | 必须在前 3 秒展现高冲击力动作或痛点，否则用户快速划走 |
| 场景叙事钩子 | 用真实生活场景取代枯燥参数说明 | 办公劳损、差旅压力、长期颈部疲劳等痛点比参数更有说服力 |
| 可信度翻译 | 把“可信”这个形容词翻译成用户能看懂的技术选择 | 可信不是营销话术，是一组具体的工程决策 |
| 数据赛马机制 | 每周持续数据迭代，精准筛选优质素材 | 及时淘汰转化不佳的达人阵营，保护并优化营销预算 |
| 动态定价矩阵 | 根据内容复杂度设计分级预算结构 | 从基础口播素材到多镜头家庭/商场实景拍摄，不同档位匹配不同预算 |
| 文化壁垒修正 | 启用符合目标市场审美特征的本地化模特与配音 | 外模非本土化会导致用户信任度不高，必须本地化 |
| ROI 对赌 | 大规模推行纯佣金合作模式 | 降低品牌方 upfront 风险，激励创作者追求真实转化 |

## 3. Tech Creator GTM 标准流程

### 阶段 1：产品差异化定位

```
产品功能 → 用户认知盲区 → 差异化价值主张 → 可验证的技术指标
```

**定位检查点**
- [ ] 是否能在 30 秒内说清“用户为什么选你而不是竞品”？
- [ ] 是否已识别出用户认知中的“默认假设”？
- [ ] 是否已准备可量化的技术指标（准确率、速度、成本等）？
- [ ] 是否已设计“可信度翻译”策略，把技术优势转化为用户可感知的价值？

**认知破局策略**
- **第一层：破神化（认知教育）**
  - 针对不同垂直领域，寻找对应行业的 AI 科技博主与专业内容创作者
  - 通过真实工作流演示，让用户意识到：“ChatGPT 已经够了”的市场默认假设不成立
  - 例如：帮助用户节省大量阅读时间、AI 在财报/医疗/法律的真实代价、如何处理法律文件提升决策可信度

- **第二层：立差异（可信技术解构）**
  - 把“可信”翻译成用户能看懂的技术选择
  - 主题角度：训练解决了什么、如何提升准确率、基于原文在架构层面意味着什么、和通用模型的准确率实测对比
  - 让用户意识到：可信不是营销话术，是一组具体的工程决策

- **第三层：凸显价值（真实工作流）**
  - 通过真实工作流演示，让用户看到产品在实际场景中的价值
  - 例如：AI 如何分析财报、如何辅助阅读医疗报告、如何快速提炼行业研究报告

**反模式**
- 单纯强调功能参数，不解决用户认知盲区
- 用泛娱乐创作者代言科技产品，无法建立专业信任
- 只做品牌曝光，不做转化漏斗设计

### 阶段 2：达人矩阵设计

**金字塔模型**

| 层级 | 占比 | 角色 | 内容策略 | 目标 |
|------|------|------|----------|------|
| 头部达人 | 5% | 品牌广泛背书 | 深度场景化讲解、行业影响力 | 快速建立初始知名度 |
| 腰部达人 | 20% | 精准圈层种草 | 专业细节展示、产品实测 | 驱动核心销售转化 |
| 尾部 KOC | 75% | 高性价比测试 | 快速测试受众偏好、素材验证 | 低成本验证内容方向 |

**达人筛选标准**
- **赛道匹配**：科技/软件/硬件等垂直领域
- **粉丝数**：根据预算和目标选择头部/腰部/尾部
- **互动率**：高于行业平均水平的达人优先
- **内容风格**：与品牌调性高度契合
- **历史数据**：过往合作转化率、受众画像

**Gotchas**
- 不要只看粉丝数；互动率比粉丝数更重要
- 头部达人做背书，但腰部达人才是转化的主力
- 尾部 KOC 用于快速测试，不是用于品牌建设
- 必须建立“熟人资源”网络；通过现有 KOL 推荐新 KOL，信任传递效率更高

### 阶段 3：AI 驱动的匹配与触达

**核心运作机制**

```
输入产品描述 → AI 智能精准匹配 → 触达策略与模板生成 → 全链路追踪与增长优化
```

**AI Agent 工作流**

1. **智能规划 AI Agent**
   - 了解品牌定位、目标受众、产品卖点和预算
   - 明确平台、合作规模、内容形式，以及合作周期
   - 输出达人筛选标准和合作框架

2. **Tech Creator Recruiting ROI AI Agent**
   - 根据赛道、粉丝数、互动率等数据筛选合适网红
   - 批量联系并确认合作意向，包含报酬形式与排期

3. **内容审核 AI Agent**
   - 提前审阅博主的拍摄计划等，确保符合品牌要求
   - 仅限于愿意提供此项合作的网红

4. **发布确认 AI Agent**
   - 检查网红是否按时发布
   - 优质内容提醒客户在品牌官方账号转发，或其他广告渠道进行二次放大

5. **数据收集 AI Agent**
   - 收集内容播放量、互动率、点击率和转化率等核心指标
   - 总结投放效果，分析是否达到既定目标

6. **关系管理 AI Agent**
   - 保持与已合作网红的联系
   - 定期与品牌方交流，更新营销思路和需求
   - 持续挖掘新网红资源，打造更丰富的合作矩阵

**Gotchas**
- AI 匹配的核心是“预训练算法深度剖析科技知识博主的历史内容、语调风格及垂直受众”
- 不要依赖关键词匹配；必须理解内容调性和受众匹配度
- 模板生成必须个性化；批量群发邮件打开率极低
- 全链路追踪必须包含转化数据，不只是曝光和播放

### 阶段 4：内容策略与创意生产

**黄金 3 秒法则**
- 视频开篇必须展现高冲击力动作或痛点
- 例如：手机剧烈晃动测试、卡包支架形态快速切换
- 防止用户在手机端快速划走

**内容矩阵设计**

| 内容类型 | 平台 | 目标 | 示例 |
|----------|------|------|------|
| 顶级教程频道 | YouTube | 深度教育、SEO 沉淀 | 产品使用教程、对比评测 |
| 联盟口碑生态 | Instagram Reel | 视觉种草、年轻受众 | 开箱视频、使用场景 |
| GEO 内容 | Reddit/Quora/G2 | 搜索信任、决策参考 | 深度问答、用户评测 |

**案例：AI PDF co-pilot × KOL 内容矩阵**
- YouTube 顶级教程频道：月均 1,100+ 万次观看，CPM <$0.02
- YouTube 联盟口碑生态：100+ 品牌视频，爆款稳定产出
- Instagram Reel：高频刷脸，建立年轻用户认知
- Reddit/Quora/G2：搜索信任，影响购买决策

**案例：SKG 智能颈肩按摩仪**
- 痛点直击：办公久坐习惯、差旅压力、长期颈部疲劳
- 价值外显：特写镜头展现专业按摩触头细节
- 用户实证：借助真实的达人口碑证言及使用前后对比

**案例：Supercase 磁吸钱包**
- 黄金 3 秒：开场展示高冲击力动作（疯狂晃动测试、模式切换）
- 场景化实测：特写跟拍镜头，直观展现顺利塞入 5+ 卡 + 现金的实用场景
- 文化壁垒修正：启用符合美国主流审美特征的白人模特，搭配地道的英语原生配音

**Gotchas**
- 场景叙事钩子 > 产品参数说明
- 真实工作流演示 > 功能列表
- 本地化 > 全球化模板
- 数据反哺迭代：提炼已被验证成功的爆款黄金前三秒钩子，直接反哺后续视频生产

### 阶段 5：数据优化与 ROI 放大

**核心指标体系**

| 指标 | 定义 | 行业基准 | 优化目标 |
|------|------|----------|----------|
| 曝光量 | 内容被展示次数 | - | 持续增长 |
| 互动率 | 点赞/评论/分享/观看 | 2.5% | > 3.5% |
| 项目点击率 | 点击链接/购买链接 | 2.13% | > 4% |
| 转化率 | 点击后实际购买 | 0.6-1.5% | > 1.94% |
| ROI | 广告投资回报率 | - | +45% 增长 |
| 完播率 | 视频完整观看比例 | 16.9% | > 90% |
| 退单率 | 退货比例 | 16.9% | < 3% |

**数据赛马机制**
1. **周度数据看板**：每周追踪播放量、互动率、转化率和最终结账下单量
2. **末位淘汰**：及时剪除转化不佳的达人阵营，保护并优化营销预算
3. **脚本反哺迭代**：提炼已被验证成功的爆款黄金前三秒钩子，直接反哺和指导后续的视频生产
4. **实时动态调整**：每周执行动态数据复盘，及时淘汰表现不佳的达人创意链路

**动态定价矩阵**
- $200 基础口播素材
- $450 多镜头家庭/商场实景拍摄
- 根据预算和内容复杂度匹配不同档位
- 最大化提升预算使用效率

**Gotchas**
- 不要追求“一次爆量”；建立可持续的内容生产 pipeline
- 数据复盘必须每周执行；市场反馈速度远比你想象的快
- ROI 优化不是“省钱”，而是“把钱花在转化率更高的地方”
- 必须建立可复用的内容资产；319+ 条短视频沉淀为品牌长期资产

## 4. 高频场景脚本

### 4.1 场景：科技产品首次进入海外市场

**执行脚本**
1. 识别产品差异化价值主张，翻译成目标市场用户能感知的“可信度指标”
2. 设计达人金字塔：5% 头部背书 + 20% 腰部转化 + 75% 尾部测试
3. 选择 3-5 个核心市场（英/美/加/德/法），匹配本地化达人资源
4. 设计内容矩阵：YouTube 深度教育 + Instagram 视觉种草 + Reddit/Quora 搜索信任
5. 建立周度数据复盘机制，设置末位淘汰规则

**Gotchas**
- 北美市场高度同质化，必须找到“突破市场盲区”的差异化切入点
- 本地化不只是语言翻译；模特、场景、配音都必须本土化
- 纯佣金合作（ROI 对赌）是降低 upfront 风险的有效方式

### 4.2 场景：AI 软件产品需要建立专业信任

**执行脚本**
1. 识别用户认知盲区：用户误以为“ChatGPT 已经够了”
2. 设计三层认知破局：破神化 → 立差异 → 凸显价值
3. 选择垂直领域 AI 博主（财报分析、医疗报告、法律文件等）
4. 通过真实工作流演示，让用户意识到“通用 AI 在专业场景的局限性”
5. 用技术指标对比建立可信度：准确率、幻觉率、处理速度等

**Gotchas**
- 不要和 ChatGPT 直接对标；要找“ChatGPT 不够好”的具体场景
- 专业场景的教育成本高，但转化后的 LTV 也高
- 必须提供可量化的技术指标，不能只靠营销话术

### 4.3 场景：硬件产品在 TikTok 上规模化推广

**执行脚本**
1. 设计黄金 3 秒钩子：高冲击力动作或痛点场景
2. 搭建金字塔达人矩阵，重点投放腰部达人（20%）
3. 每周数据复盘，淘汰转化率低的达人
4. 提炼爆款钩子，反哺后续内容生产
5. 建立动态定价矩阵，匹配不同预算和内容复杂度

**Gotchas**
- TikTok 用户划走速度极快，前 3 秒决定成败
- 硬件产品必须展示“真实使用场景”，不能只是参数罗列
- 完播率是 TikTok 算法的核心指标，必须优先优化
- 本地化模特和配音对建立信任至关重要

### 4.4 场景：需要建立可复用的达人营销基础设施

**执行脚本**
1. 设计 6 个 AI Agent 工作流：智能规划、达人招募、内容审核、发布确认、数据收集、关系管理
2. 建立达人数据库：2.5 亿+ 网红详细数据库，覆盖 5 大平台
3. 开发自研红人触达平台（如 Bizkol AI），实现跨平台发现与触达
4. 沉淀内容 SOP：从创意生产到发布确认的标准流程
5. 建立数据看板：实时监控投放效果，支持周度复盘

**Gotchas**
- AI Agent 不能完全替代人工判断；内容审核和创意决策仍需人类参与
- 达人数据库需要持续更新和维护；网红活跃度和受众画像都会变化
- 关系管理是长期资产；不要用完即扔，要持续 nurturing

### 4.5 场景：衡量科技产品 KOL 营销效果

**执行脚本**
1. 建立核心指标体系：曝光量、互动率、点击率、转化率、ROI、完播率、退单率
2. 设置行业基准线：互动率 >3.5%、点击率 >4%、转化率 >1.94%、ROI +45%
3. 设计数据赛马机制：周度追踪、末位淘汰、脚本反哺
4. 对比品类基准线：评估表现是否优于行业平均
5. 计算真实 ROI：考虑产品售价、客单价、复购率等因素

**Gotchas**
- 曝光量 ≠ 有效触达；必须关注互动率和完播率
- 点击率提升需要对比基准线，不能只看绝对值
- ROI 计算必须包含所有成本：达人费用、内容制作、平台投放、人力成本
- 退单率是硬件产品的关键指标，必须持续监控

### 5.1 Tech Creator GTM 策略文档

## 6. 环境与执行约定

- 所有策略必须基于真实数据；不用“感觉”“可能”“大概”作为决策依据
- 达人匹配必须基于内容调性和受众匹配度，不只是关键词匹配
- 内容策略必须包含“黄金 3 秒”设计，不能只写大纲不解决开篇留存
- 数据复盘必须每周执行，建立“数据赛马机制”
- 本地化是硬件产品进入海外市场的必要条件，不能跳过
- ROI 计算必须包含所有成本，不能只看 GMV
- 输出结构统一为：产品定位 → 达人矩阵 → 内容策略 → AI Agent 工作流 → 数据优化 → 风险提示

## 7. 风险提示

| 风险 | 表现 | 拦截方式 |
|------|------|----------|
| 认知错位 | 用户不知道产品能解决什么问题 | 先做认知教育，再做产品推广 |
| 达人错配 | 达人调性与品牌不符 | AI 匹配 + 人工审核双重确认 |
| 内容同质化 | 创意文案重复枯燥，完播率低 | 场景化实测、用户实证、黄金 3 秒钩子 |
| 本地化不足 | 外模/配音导致信任度低 | 本地模特、原生配音、本土场景 |
| 数据黑盒 | 不知道钱花在哪里、效果如何 | 全链路追踪、周度数据看板 |
| ROI 不达标 | 广告投入产出比低于预期 | 动态定价、末位淘汰、预算重分配 |
| 供应链瓶颈 | 爆单后无法及时发货 | 提前验证供应链能力，设置库存预警 |
| 合规风险 | 海外市场广告法规差异 | 本地化合规审查，避免夸大宣传 |

## 输出规范（validate.py 断言）

本技能产出的分析/方案文档，必须同时满足：
- **应含**：本文件输出规范所列合规要素
- **不应含**：红线违规模式（详见 scripts/validate.py BAD_VIOLATIONS）

校验命令：`python scripts/validate.py <文档路径>`（exit 0=通过，1=违规或缺失，2=文件错误）
