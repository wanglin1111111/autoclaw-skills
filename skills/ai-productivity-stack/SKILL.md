# AI Productivity Stack

> 你的下一个同事，是 AI。
> 这场效率革命的核心，正是 AI——它并非遥不可及的科幻概念，而是自"算力"和"互联网"之后，第三次赋能个体的革命性力量。
> 这个 Skill 帮你构建"豆包 + 即梦 + 剪映 + 飞书 + 扣子"五合一 AI 生产力工作环境，从执行者升级为指挥 AI 工具队伍协同工作的"指挥官"。

## 1. 核心定位

**不是什么**：不是单一工具的操作手册，不是编程教程，不是通用 AI 理论。

**是什么**：一个国产主流 AI 工具的组合提效工作环境，聚焦职场人士、管理者、内容创作者的日常办公场景。

**解决什么问题**：
- 面对 5 款 AI 工具不知如何组合使用形成合力
- 会操作工具但无法产出专业级内容
- 提示词质量低，AI 响应不符合预期
- 重复性工作占用大量时间，缺乏自动化思维
- 不会用 AI 进行视觉设计、视频制作、知识管理

## 2. 任务边界

### 包含
- 豆包：AI 搜索、AI 写作、AI 阅读、AI PPT 生成
- 即梦：AI 图片生成、AI 视频生成
- 剪映：智能图文成片、口播剪辑、数字人讲解、多语言视频翻译、智能字幕
- 飞书：多维表格、AI 知识库、团队协作流程优化
- 扣子：AI 智能体定制、自动化工作流搭建
- 提示词工程：万能公式、迭代优化技巧、多轮对话策略
- AI 工作流：从单点工具到端到端自动化闭环

### 不包含
- 不负责工具账号开通、付费订阅等外部服务对接
- 不负责代码开发（扣子可视化搭建除外）
- 不负责视频拍摄、专业设计等线下生产环节
- 不负责替代最终决策，AI 产出需人工审核

## 3. 核心概念

### 3.1 五工具定位矩阵

| 工具 | 核心能力 | 最佳场景 | 输入方式 |
|------|---------|---------|---------|
| **豆包** | 文本理解与生成 | 搜索、写作、阅读、PPT | 自然语言 |
| **即梦** | 视觉内容生成 | 海报、配图、短视频、形象照 | 文字描述 |
| **剪映** | 视频编辑与增强 | 口播、宣传片、数字人、字幕 | 视频素材+文字 |
| **飞书** | 团队协作与知识管理 | 表格、文档、知识库、项目管理 | 结构化数据 |
| **扣子** | 智能体与自动化 | 专属助手、工作流、自动推送 | 可视化配置 |

### 3.2 提示词万能公式

```
【场景定位】角色定义 + 品牌信息 + 用户画像
【目标明确】具体动作 + 交付成果名称 + 数量要求
【要求细化】输出结构 + 量化指标 + 排除项
```

**示例**：
```
【场景定位】你是一位顶级的 4A 广告公司首席创意官。我现在正在为一个主打"自然、活力、年轻"的新兴饮料品牌服务，其核心目标用户是 Z 世代和都市年轻白领。

【目标明确】现在，请你为即将到来的夏季，构思 3 套完全不同方向的营销活动方案。

【要求细化】每一套营销活动方案都必须包含以下 5 个部分，并严格按照此结构输出：
1. 主题名称：给这个活动起一个易于传播的名字。
2. 核心口号：用最短的语言，戳中最深的痛点，让人立刻想行动起来。
3. 用户洞察：简述这个创意是基于对年轻人何种心理或行为的洞察。
4. 创意故事：详细描述这个创意的核心内容是什么，它如何展开。
5. 渠道建议：建议主要在哪些渠道（如抖音、小红书、B站、线下活动）进行传播。

请注意，最终交付的内容必须严格采用 Markdown 格式。
活动口号必须在 12 个字以内。创意故事的篇幅严格控制在 200-250 字。
请直接开始输出第一个方案，不要包括任何开场白、结束语或对你所创创意的额外解释。你的回答应该直接以"方案一："开始。
```

### 3.3 多轮对话三阶段

**第一阶段：定义问题**
- 明确核心目标（可衡量的业务成果）
- 整理已有信息（确定性信息）
- 识别信息缺口（最需要 AI 帮助的关键问题）

**第二阶段：迭代方案**
- 补充关键信息：成功范例、负面清单、竞争格局
- 调整表述方式：形容词→动词+方法，角色扮演/风格类比，引导性问题
- 限定输出边界：格式规范、量化指标、排除无关内容

**第三阶段：总结复盘**
- 让 AI 对全过程进行归纳
- 形成逻辑清晰、可直接使用的最终成果
- 提取可复用的方法论

### 3.4 工作流自动化层次

```
L1 单点工具：豆包写文案 → 手动复制到剪映 → 手动导出
L2 工具串联：豆包写脚本 → 剪映自动生成视频 → 手动发布
L3 智能体：扣子搭建"AI 视频制作Agent" → 输入主题 → 自动完成全流程
L4 自动化流：扣子工作流 → 定时触发 → 自动收集行业新闻 → 自动生成日报 → 自动推送
```

## 4. 标准流程

### 4.1 内容创作流程（文字→图片→视频）

```
Step 1: 内容策划（豆包）
  ├─ 使用万能公式生成文案脚本
  ├─ 多轮迭代优化直到满意
  └─ 输出结构化脚本（旁白、镜头、时长）

Step 2: 视觉生成（即梦）
  ├─ 根据脚本描述生成配图/海报
  ├─ 统一风格提示词确保视觉一致性
  └─ 生成视频首帧或关键帧

Step 3: 视频制作（剪映）
  ├─ 图文成片：导入脚本自动匹配画面
  ├─ 口播剪辑：智能字幕、去除 silence、添加 BGM
  ├─ 数字人：生成虚拟人讲解视频
  └─ 多语言翻译：一键生成多语言版本

Step 4: 知识沉淀（飞书）
  ├─ 将成品上传至知识库
  ├─ 多维表格记录内容数据
  └─ 团队协作反馈收集

Step 5: 自动化升级（扣子）
  ├─ 将流程固化为智能体
  ├─ 创建工作流实现一键生成
  └─ 配置定时推送实现自动化
```

### 4.2 提示词优化流程

```
原始需求 → 场景定位 → 目标明确 → 要求细化 → AI生成 → 迭代优化 → 最终交付
   ↑                                                                 |
   └─────────────────────────────────────────────────────────────────┘
```

**迭代优化三要素**：
1. **补充关键信息**：成功范例、负面清单、竞争格局
2. **调整表述方式**：形容词→动词+方法，角色扮演，引导性问题
3. **限定输出边界**：格式规范、量化指标、排除无关内容

### 4.3 团队知识管理流程

```
Step 1: 知识库搭建（飞书）
  ├─ 新建知识库，定义分类结构
  ├─ 批量导入现有文档
  └─ 设置权限（内部/外部/指定页面）

Step 2: 知识运营
  ├─ 定期更新维护
  ├─ 对外分享指定页面
  └─ 邀请协作者共同编辑

Step 3: 智能问答
  ├─ 为知识库开启问答功能
  ├─ 训练 AI 基于知识库回答
  └─ 越用越智能（持续学习）

Step 4: 自动化（扣子）
  ├─ 创建"知识助手"智能体
  ├─ 绑定知识库作为数据源
  └─ 嵌入工作流实现自动问答
```

## 5. 场景脚本

### 场景1：营销活动策划（豆包+飞书）

**背景**：小王是品牌策划，需要为新品饮料构思夏季营销活动。

**脚本**：
```
用户：我需要策划一个夏季营销活动，主打自然、活力、年轻，目标用户是 Z 世代和都市白领。

AI（豆包）：
【场景定位】你是一位顶级的 4A 广告公司首席创意官...

【目标明确】构思 3 套完全不同方向的营销活动方案...

【要求细化】每套方案包含：主题名称、核心口号（12字以内）、用户洞察、创意故事（200-250字）、渠道建议...

用户：请参考去年"城市探索咖啡地图"的成功经验（UGC+社区感），避免使用明星代言和硬性打折。

AI（豆包）：（基于补充信息优化方案）

用户：请用 Markdown 格式输出，直接以"方案一："开始。

AI（豆包）：（最终交付）
```

**输出**：3 套可直接提案的营销活动方案

**后续**：将方案同步至飞书知识库，团队协作反馈

```
- 配置每个节点的参数

- 发布工作流
- 设置触发条件
- 观察运行结果并优化
```


## 7. 关键技巧速查

### 豆包技巧
- **万能公式**：场景定位 + 目标明确 + 要求细化
- **多轮对话**：定义问题 → 迭代方案 → 总结复盘
- **提示词优化**：补充关键信息、调整表述方式、限定输出边界

### 即梦技巧
- **风格统一**：在提示词中固定风格描述词（如"赛博朋克风格"）
- **角色一致性**：使用同一角色描述词确保人物形象统一
- **视频生成**：首帧图 + 运动描述 = 可控视频

### 剪映技巧
- **图文成片**：脚本 → 自动匹配画面 → 一键成片
- **口播优化**：自动字幕 + 去 silence + 音量标准化
- **数字人**：无需出镜，输入文案生成讲解视频
- **多语言**：一键翻译配音，快速出海

### 飞书技巧
- **多维表格**：替代 Excel，支持看板、甘特图、日历视图
- **知识库**：批量导入、权限管理、对外分享、智能问答
- **协作流程**：评论@、任务分配、版本历史

### 扣子技巧
- **智能体**：人设 + 知识库 + 技能 = 专属 AI 助手
- **工作流**：可视化拖拽，支持复杂业务逻辑
- **自动推送**：定时触发、事件驱动、多渠道发布

## 8. 常见陷阱与规避

### 陷阱1：提示词过于模糊
- **表现**："帮我写个文案" → AI 输出通用模板
- **规避**：使用万能公式，提供场景、目标、要求

### 陷阱2：一次定稿
- **表现**：对首次输出不满意，放弃使用
- **规避**：准备迭代清单，多轮优化直到满意

### 陷阱3：工具孤立使用
- **表现**：豆包写完复制到剪映，手动调整
- **规避**：用扣子搭建工作流，实现端到端自动化

### 陷阱4：过度依赖 AI
- **表现**：AI 输出错误信息直接使用
- **规避**：关键信息人工复核，建立审核机制

### 陷阱5：忽略团队协作
- **表现**：个人使用，成果无法共享
- **规避**：优先使用飞书生态，知识沉淀至知识库
