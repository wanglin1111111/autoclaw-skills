# 思维模型应用模板集

## 模板 1：个人成长计划模板

```markdown
# 个人成长计划：[姓名] - [时间段]

## 当前状态诊断
- 达克效应自评：[ ] 不知道自己不知道 [ ] 知道自己不知道 [ ] 知道自己知道 [ ] 不知道自己知道
- 当前人生坐标：[ ] 我好-你好 [ ] 我好-你不好 [ ] 我不好-你好 [ ] 我不好-你也不好
- 能量状态评估：[ ] 高能量正向 [ ] 高能量负向 [ ] 低能量正向 [ ] 低能量负向

## 核心模型选择
| 领域 | 选用模型 | 应用方式 | 成功标准 |
|------|---------|---------|---------|
| 职业发展 | EBSI四象限 + 事业定位四象限 | 每月复盘一次象限位置 | 明确下季度象限迁移路径 |
| 目标管理 | OKR + 1-3-5清单 | 每周一定OKR，每日做1-3-5 | 关键结果完成率 > 80% |
| 学习提升 | 费曼学习法 + 刻意练习 | 每周输出1篇学习笔记 | 笔记被他人引用/采纳 |
| 习惯养成 | MAP原则 | 每月养成1个新习惯 | 连续执行 > 66天 |

## 执行计划
### 短期（1个月）
- [ ] 完成自我认知校准
- [ ] 建立基础清单体系
- [ ] 启动第一个习惯养成

### 中期（3个月）
- [ ] 形成稳定的工作流
- [ ] 完成1-2个核心技能提升
- [ ] 建立复盘机制

### 长期（12个月）
- [ ] 完成象限迁移（如从E到S/I）
- [ ] 建立可复制的个人系统
- [ ] 成为某一领域的实践者/分享者

## 复盘机制
- 日复盘：1-3-5清单完成情况
- 周复盘：KPT（Keep/Problem/Try）
- 月复盘：四象限位置变化 + 能量状态评估
- 年复盘：英雄之旅阶段评估 + 下一段旅程规划
```
