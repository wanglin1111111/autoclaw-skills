# Thinking Models

> 思维模型是认知的武器库。不是知道越多越好，而是在关键时刻能调出正确的模型。
> 这个 Skill 帮你建立系统化的思维模型应用能力，把 46 个经典模型转化为可落地的个人成长工具。

## 1. 核心定位

**不是什么**：不是理论堆砌，不是心理学教材，不是成功学鸡汤。

**是什么**：一个可搜索、可组合、可落地的个人成长思维模型工具箱。

**解决什么问题**：
- 面对复杂问题时，不知道该用哪个框架思考
- 知道很多模型，但不会在实际场景中组合应用
- 学习了很多成长方法，但无法形成系统

**适用人群**：
- 追求系统性成长的职场人
- 需要做决策的管理者
- 希望提升认知深度的终身学习者
- 处于职业转型期的探索者

## 2. 46 个思维模型分类体系

### 2.1 认知与自我认知类（8个）

| 模型 | 英文 | 一句话定义 | 核心用途 |
|------|------|-----------|---------|
| 达克效应 | Dunning-Kruger Effect | 能力不足者往往高估自己，能力强者往往低估自己 | 校准自我认知，避免认知偏差 |
| 冰山模型 | Iceberg Model | 能力像冰山，水面以上是知识技能，水面以下是特质动机 | 全面评估自己或他人 |
| 约哈里视窗 | Johari Window | 通过反馈发现盲点，扩大共识区 | 增强自我意识，改善人际关系 |
| 成长破圈模型 | Growth Breakthrough | 突破舒适区、恐惧区、学习区，进入成长区 | 设计个人成长路径 |
| NLP 思维层次 | NLP Logical Levels | 从环境到精神，六个层次递进 | 找到问题的真正层次 |
| 马斯洛需求层次 | Maslow's Hierarchy | 五层需求从低到高，逐层满足 | 理解动机，诊断瓶颈 |
| 人生坐标 | Life Position | 早期信念决定「我好-你不好」等四种坐标 | 觉察底层信念，调整人生脚本 |
| 英雄之旅 | Hero's Journey | 每个人都要走平凡→启程→考验→归来的旅程 | 重构人生叙事，找到使命感 |

## 3. 思维模型应用标准流程

### 阶段 1：问题诊断 — 选择正确的模型

**选择决策树**

```
问题类型是什么？
├── 自我认知不清楚 → 达克效应 + 冰山模型 + 约哈里视窗
├── 职业方向迷茫 → EBSI四象限 + 事业定位四象限 + 职业锚
├── 目标不清晰 → OKR + SMART + 目标制定七步清单
├── 优先级混乱 → 艾森豪威尔矩阵 + 1-3-5清单 + 优先级矩阵
├── 知识学不会 → 费曼学习法 + 刻意练习 + 721学习法则
├── 习惯养不成 → MAP习惯原则 + 习惯养成清单
├── 情绪不稳定 → 人类能量四象限 + 非暴力沟通
├── 决策困难 → 第一性原理 + 第二序思维 + SWOT
└── 表达不清楚 → PREP + SCQA + 金字塔原理
```

**模型选择检查点**
- [ ] 问题是否被准确分类？（不要用错模型）
- [ ] 是否只选 1-2 个核心模型？（避免分析瘫痪）
- [ ] 模型是否适合当前阶段？（新手不要用高级模型）
- [ ] 是否有验证标准？（知道应用后如何衡量效果）

### 阶段 2：模型内化 — 把知识变成能力

**三步内化法**

1. **理解阶段**：用自己的话重述模型核心逻辑
   - 这个模型解决什么问题？
   - 核心假设是什么？
   - 适用边界在哪里？

2. **应用阶段**：在低风险场景中练习
   - 今天/本周能用在哪里？
   - 最小可行应用是什么？
   - 如何快速获得反馈？

3. **反思阶段**：复盘应用效果
   - 模型是否有效？
   - 哪里用错了？
   - 下次如何改进？

### 阶段 3：模型组合 — 建立个人系统

**组合原则**

| 场景 | 模型组合示例 |
|------|-------------|
| 年度规划 | 目标制定七步 → OKR → 甘特图 → 1-3-5清单 |
| 职业转型 | 事业定位四象限 → 职业锚 → SWOT → 安索夫矩阵 |
| 知识学习 | 费曼学习法 → 刻意练习 → 知识管理六清单 |
| 习惯养成 | 人类能量四象限 → MAP原则 → 习惯养成清单 |
| 沟通提升 | 非暴力沟通 → 约哈里视窗 → PREP/SCQA |
| 复盘反思 | KPT/PDCA/KISS → 四行日记 → 第二序思维 |

### 阶段 4：持续迭代 — 模型进化的闭环

```
应用模型 → 收集反馈 → 反思效果 → 调整模型 → 再次应用
```

**进化信号识别**
- 模型在新场景下失效 → 需要扩展边界或寻找新模型
- 多个模型结论冲突 → 需要整合或建立选择标准
- 模型应用成本过高 → 需要简化或自动化
- 身边人开始用同一模型 → 需要寻找差异化模型

## 5. 场景脚本库

### 5.1 职业迷茫期

**特征**：不知道自己喜欢什么、擅长什么、能做什么

**推荐流程**：
1. 用 `冰山模型` 全面盘点自己（知识、技能、特质、动机）
2. 用 `EBSI 四象限` 评估当前财富路径
3. 用 `人生事业定位四象限` 找到甜蜜区（喜欢 + 擅长）
4. 用 `职业锚` 确认核心价值观
5. 用 `英雄之旅` 重构职业叙事，找到使命感

**输出物**：个人职业定位报告 + 3年成长路线图

### 5.2 目标达成困难

**特征**：定了很多目标，完成的很少

**推荐流程**：
1. 用 `OKR` 重新设定目标（确保有激情、有挑战、有时限）
2. 用 `SMART` 检查目标质量
3. 用 `艾森豪威尔矩阵` 重新排序当前任务
4. 用 `1-3-5 清单` 拆解每日行动
5. 用 `复盘四张清单` 每周回顾

**输出物**：OKR 系统 + 每日执行清单 + 周复盘模板

### 5.3 知识消化不良

**特征**：学了很多，记不住，用不上

**推荐流程**：
1. 用 `费曼学习法` 检验是否真懂（能教别人吗？）
2. 用 `721 学习法则` 调整学习配比（少上课，多实践）
3. 用 `知识管理六清单` 建立笔记系统
4. 用 `刻意练习` 在关键技能上突破
5. 用 `金字塔原理` 整理输出

**输出物**：个人知识管理系统 + 深度学习计划

### 5.4 习惯养不成

**特征**：三分钟热度，无法坚持

**推荐流程**：
1. 用 `人类能量四象限` 评估当前能量状态
2. 用 `MAP 原则` 设计习惯（Motivation + Ability + Prompt）
3. 用 `习惯养成清单` 逐步建立
4. 用 `1-3-5 清单` 把习惯嵌入每日流程
5. 用 `KPT 复盘` 每周调整

**输出物**：习惯养成系统 + 能量管理方案

### 5.5 沟通冲突

**特征**：说话没人听，吵架总输，表达不清楚

**推荐流程**：
1. 用 `约哈里视窗` 扩大共识区（减少盲点）
2. 用 `非暴力沟通` 重构对话（观察-感受-需要-请求）
3. 用 `PREP` 或 `SCQA` 组织表达逻辑
4. 用 `关键对话` 处理高风险沟通

**输出物**：沟通改进计划 + 表达结构模板

## 6. 风险提示与避坑指南

### 6.1 模型误用风险

| 风险 | 表现 | 规避策略 |
|------|------|---------|
| 模型崇拜 | 把模型当真理，忽视现实复杂性 | 记住：模型是地图，不是领土 |
| 分析瘫痪 | 学了很多模型，反而不敢行动 | 限制：同时最多用 2-3 个模型 |
| 生搬硬套 | 不顾场景强行套用 | 先理解模型假设，再判断是否匹配 |
| 唯效率论 | 把所有事情都变成效率优化 | 有些领域需要留白、探索、浪漫 |
| 忽视人性 | 把人当系统优化对象 | 人是目的，不是手段 |

### 6.2 常见陷阱

**陷阱 1：用战术勤奋掩盖战略懒惰**
- 表现：沉迷于时间管理、习惯养成，逃避真正重要的人生选择
- 破解：先用 `人生事业定位四象限` 确认方向，再用 `OKR` 执行

**陷阱 2：用学习代替行动**
- 表现：收藏了很多模型，读了很多书，但生活没有改变
- 破解：`费曼学习法` + `刻意练习`，输出倒逼输入

**陷阱 3：追求完美模型**
- 表现：总觉得还没准备好，需要再学一个模型
- 破解：`70% 原则`，现有知识足够就开始，在行动中迭代

**陷阱 4：忽视能量管理**
- 表现：只优化时间，不优化状态，越忙越累
- 破解：`人类能量四象限`，先管理能量，再管理时间

### 6.3 模型组合禁忌

```
❌ 不要组合：
- 两个分析型模型（如 SWOT + 波士顿矩阵）→ 都会陷入分析瘫痪
- 两个执行型模型（如 OKR + 甘特图）→ 都会变成工具奴隶
- 高维模型 + 低维问题（如第一性原理 + 今天吃什么）→ 杀鸡用牛刀

✅ 应该组合：
- 分析型 + 执行型（如 SWOT + OKR）
- 认知型 + 行动型（如 冰山模型 + 习惯养成）
- 短期工具 + 长期框架（如 1-3-5清单 + 英雄之旅）
```
