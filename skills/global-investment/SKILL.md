# Global Investment

> 在全球视野下，投资的核心是把握趋势。趋势就在那里，只是需要你穿透迷雾看见它。
> 这个 Skill 帮你建立系统化的全球投资分析能力，把宏观经济周期、资本流动、产业趋势转化为可执行的资产配置方案。

## 1. 核心定位

**不是什么**：不是荐股软件，不是短期交易信号，不是暴富捷径。

**是什么**：一个基于周期理论和全球视野的投资分析工作环境。

**解决什么问题**：
- 面对复杂多变的全球经济，不知道如何把握大趋势
- 知道很多投资品种，但不知道如何配置和择时
- 听了很多分析，但无法形成自己的判断框架

**适用人群**：
- 有闲置资金需要配置的中产及以上投资者
- 关注全球资产配置的高净值个人
- 希望理解经济趋势的终身学习者
- 需要宏观视角的专业投资者

## 2. 核心分析框架

### 2.1 四维周期嵌套模型

这是时寒冰在本书中创造的方法论革命，将四种经济周期与人口、资本流动结合，编织成观察全球经济的"天罗地网"。

| 周期类型 | 周期长度 | 驱动因素 | 投资含义 |
|----------|---------|---------|---------|
| 基钦周期 | 3-4年 | 库存波动 | 短周期择时，捕捉库存拐点 |
| 朱格拉周期 | 7-10年 | 设备更替 | 中周期布局，把握产业升级 |
| 库兹涅茨周期 | 15-25年 | 房地产/建筑兴衰 | 长周期配置，识别地产拐点 |
| 康德拉季耶夫周期 | 50-60年 | 技术革命 | 超长周期战略，押注技术变革 |

**嵌套原理**：短周期嵌套在长周期中，共同决定经济大趋势。当多个周期同向时，趋势最强；当周期背离时，需要辨别主导力量。

**人口与资本流动补充维度**：
- 人口迁移方向 = 资本长期流向
- 人口流入地 → 资产价格上涨（股市、楼市）
- 人口流出地 → 资产价格下跌

### 2.2 高盈利源头分析

**核心公式**：
```
高盈利 = 趋势 × 稀缺性 × 资本流动方向
```

**三大源头**：

1. **趋势**：与确定趋势同行
   - 产业大转移方向（如第五次产业大转移：高端产业回流发达国家，低端产业流向东南亚、墨西哥）
   - 技术革命方向（如人工智能、新能源）
   - 政策支持方向（如去美元化、核电发展）

2. **稀缺性**：紧抓稀缺性
   - 资源稀缺（如稀土、钴、锆）
   - 产能稀缺（如核电产能）
   - 时间稀缺（如早期布局窗口）

3. **资本流动**：跟着资本走
   - 人口流入 → 资本流入 → 资产价格上涨
   - 人口流出 → 资本流出 → 资产价格下跌
   - 全球资本追逐的方向 = 投资机会所在

### 2.3 货币体系分析框架

**货币支撑逻辑**：
```
货币价值 = 国家信用 × 经济实力 × 军事力量 × 国际规则话语权
```

**货币博弈层次**：

| 层次 | 内容 | 投资含义 |
|------|------|---------|
| 国家信用 | 债务违约风险、财政可持续性 | 高债务国家货币承压 |
| 经济实力 | GDP、贸易顺差、制造业能力 | 实体经济支撑货币价值 |
| 军事力量 | 军事投射能力、地缘控制 | 强势军事支撑货币霸权 |
| 规则话语权 | SWIFT、IMF、国际结算体系 | 规则制定者获得货币特权 |

**去美元化趋势分析**：
- 美元霸权基石：石油美元 + 美债市场深度 + SWIFT体系
- 去美元化动力：美国债务高企、地缘冲突、结算风险
- 去美元化路径：本币结算、黄金储备、数字货币、区域货币联盟
- 投资机会：黄金、白银、人民币资产、区域货币

### 2.4 投资品种分析矩阵

| 品种 | 分析维度 | 核心指标 | 风险点 |
|------|---------|---------|--------|
| 股票 | 趋势 + 估值 + 资金流 | 市盈率、市净率、北向资金 | 估值泡沫、趋势反转 |
| 债券 | 收益率 + 信用 + 周期 | 国债收益率、信用利差 | 利率上行、违约风险 |
| 黄金 | 货币属性 + 避险 + 实际利率 | 央行购金量、美元指数、实际利率 | 实际利率上行、流动性危机 |
| 白银 | 工业属性 + 货币属性 | 金银比、光伏需求、工业需求 | 工业需求下滑 |
| 原油 | 供需 + 地缘 + 美元 | OPEC产量、库存、美元指数 | 地缘缓和、需求衰退 |
| 房地产 | 人口 + 货币 + 政策 | 人口净流入、M2增速、限购政策 | 人口流出、债务危机 |
| 核电 | 能源安全 + 技术突破 | 核准数量、技术路线、 Uranium价格 | 技术事故、政策转向 |
| 人工智能 | 技术革命 + 应用落地 | 算力需求、应用场景、专利数量 | 技术停滞、泡沫破裂 |
| 新能源 | 政策支持 + 技术进步 | 装机量、成本下降、储能突破 | 产能过剩、贸易壁垒 |
| 中医药 | 文化自信 + 人口老龄化 | 医保覆盖、出口数据、老字号 | 政策风险、质量问题 |

## 3. 全球投资分析标准流程

### 阶段 1：宏观环境扫描 — 确定大趋势方向

**扫描清单**：

1. **周期定位**
   - 当前处于哪个基钦周期阶段？（复苏/过热/滞胀/衰退）
   - 当前处于哪个朱格拉周期阶段？（设备投资高峰期/低谷期）
   - 当前处于哪个库兹涅茨周期阶段？（地产繁荣/衰退）
   - 当前处于哪个康波周期阶段？（复苏/繁荣/衰退/萧条）

2. **人口与资本流动**
   - 全球人口主要流向哪里？
   - 资本主要流入哪些国家/地区？
   - 哪些行业受益于人口流入？

3. **产业大转移**
   - 当前第几次产业大转移？
   - 产业从哪些地区转移到哪些地区？
   - 哪些行业受益于产业转移？

4. **货币体系**
   - 美元处于什么阶段？（强势/弱势）
   - 主要货币博弈格局如何？
   - 去美元化进度如何？

5. **技术革命**
   - 当前主导技术革命是什么？
   - 哪些行业是技术革命的核心受益者？
   - 技术扩散路径如何？

**输出物**：宏观环境扫描报告 + 大趋势判断

### 阶段 2：资产配置设计 — 构建投资组合

**配置框架**：

```
核心资产（60-70%）
├── 股票类（30-40%）
│   ├── 本国股市（趋势向上时超配）
│   ├── 美股（科技股/消费股）
│   └── 新兴市场股市（估值低位时配置）
├── 债券类（20-30%）
│   ├── 国债（安全垫）
│   ├── 高等级信用债
│   └── 美债（美元资产配置）
└── 现金类（10-20%）
    ├── 货币基金
    └── 短期存款

卫星资产（30-40%）
├── 贵金属（5-10%）
│   ├── 黄金（抗通胀、避险）
│   └── 白银（工业需求+货币属性）
├── 大宗商品（5-10%）
│   ├── 原油（地缘风险）
│   ├── 农产品（通胀对冲）
│   └── 工业金属（经济周期）
├── 另类资产（5-10%）
│   ├── REITs（房地产信托）
│   ├── 私募股权
│   └── 艺术品/收藏品
└── 主题投资（5-10%）
    ├── 人工智能
    ├── 新能源
    ├── 核电
    ├── 中医药
    └── 小金属
```

**配置原则**：
- 顺周期时：超配股票、大宗商品、高收益债券
- 逆周期时：超配国债、黄金、现金
- 趋势确认后逐步加仓，不追高
- 分散配置，单一资产不超过20%

### 阶段 3：个股/品种选择 — 深度研究

**选择标准**：

1. **趋势确认**
   - 是否处于长期上升趋势？
   - 产业逻辑是否清晰？
   - 政策环境是否支持？

2. **估值合理**
   - 当前估值处于历史什么分位？
   - 与同类公司相比是否合理？
   - 未来成长性是否支撑当前估值？

3. **竞争优势**
   - 护城河是什么？
   - 市场份额是否领先？
   - 技术/品牌/成本优势是否明显？

4. **财务健康**
   - 盈利能力如何？
   - 负债率是否安全？
   - 现金流是否充足？

5. **风险可控**
   - 最大回撤是多少？
   - 最坏情况会亏损多少？
   - 是否有止损策略？

**输出物**：投资标的分析报告 + 买入/卖出建议

### 阶段 4：风险管理 — 控制下行风险

**风险分层管理**：

| 风险类型 | 识别方法 | 应对策略 |
|----------|---------|---------|
| 系统性风险 | 经济衰退、金融危机 | 分散配置、对冲工具、降低权益仓位 |
| 政策风险 | 监管变化、税收调整 | 跟踪政策、分散 jurisdictions |
| 汇率风险 | 本币大幅波动 | 自然对冲、远期合约、货币分散 |
| 地缘风险 | 战争、贸易冲突 | 避险资产、分散地区 |
| 流动性风险 | 市场冻结、无法变现 | 保持现金、高流动性资产 |
| 个股风险 | 公司暴雷、财务造假 | 分散持仓、止损线、深入研究 |

**仓位管理**：
- 单只个股不超过总仓位的5%
- 单一行业不超过总仓位的20%
- 保留至少10%现金应对极端情况
- 根据趋势强度动态调整仓位（趋势强时高仓位，趋势弱时低仓位）

### 阶段 5：复盘与调整 — 持续优化

**复盘频率**：
- 日复盘：市场重大变化、个股公告
- 周复盘：组合表现、趋势变化
- 月复盘：资产配置再平衡、宏观环境更新
- 季/年复盘：深度复盘、策略调整

**复盘清单**：
- [ ] 投资逻辑是否仍然成立？
- [ ] 宏观环境是否发生重大变化？
- [ ] 个股基本面是否恶化？
- [ ] 估值是否过高/过低？
- [ ] 仓位是否需要调整？
- [ ] 是否需要止损/止盈？

## 4. 重点投资机会分析

### 4.1 人工智能

**投资逻辑**：
- 技术革命：AI 是第四次工业革命的核心驱动力
- 需求爆发：算力需求呈指数级增长
- 应用落地：从模型到应用，商业化路径清晰

**核心赛道**：
1. **算力层**：GPU、AI芯片、光模块、液冷
2. **模型层**：大模型公司、开源模型
3. **应用层**：办公软件、客服、代码助手、设计工具
4. **数据层**：数据标注、数据交易、知识图谱

**关键指标**：
- 算力需求增长率
- AI 应用渗透率
- 大模型商业化进展

**风险提示**：
- 技术迭代风险（路线变化）
- 估值泡沫风险（短期过热）
- 监管风险（数据安全、算法合规）

### 4.2 新能源

**投资逻辑**：
- 能源转型：从化石能源到可再生能源
- 成本下降：光伏、风电成本持续下降
- 政策支持：全球碳中和承诺

**核心赛道**：
1. **光伏**：硅料、硅片、电池片、组件
2. **风电**：陆上风电、海上风电
3. **储能**：锂电池、钠电池、压缩空气储能
4. **氢能**：绿氢制备、储运、应用
5. **电网**：特高压、智能电网、虚拟电厂

**关键指标**：
- 全球新增装机量
- 储能成本下降曲线
- 电网投资增速

**风险提示**：
- 产能过剩风险
- 贸易壁垒风险
- 技术路线变化风险

### 4.3 核电

**投资逻辑**：
- 能源安全：基荷能源，不受天气影响
- 减碳需求：零碳排放，满足碳中和目标
- 技术突破：小型模块化反应堆（SMR）降低建设成本

**核心赛道**：
1. **核电运营商**：中国核电、中广核电力
2. **核电设备**：东方电气、上海电气
3. **核电建设**：中国核建
4. **核燃料**：中核科技、应流股份

**关键指标**：
- 核电核准数量
- 在建核电规模
- Uranium价格

**风险提示**：
- 技术事故风险
- 公众接受度风险
- 政策转向风险

### 4.4 中医药

**投资逻辑**：
- 文化自信：中医药文化复兴
- 人口老龄化：慢性病管理需求增长
- 政策支持：中医药发展规划、医保覆盖

**核心赛道**：
1. **中药饮片**：同仁堂、云南白药、片仔癀
2. **中成药**：感冒药、心血管药、肿瘤药
3. **中医服务**：连锁诊所、中医馆
4. **中药种植**：道地药材、GAP种植基地

**关键指标**：
- 中药工业收入增速
- 医保覆盖比例
- 中药出口数据

**风险提示**：
- 质量安全风险
- 政策监管风险
- 原材料价格波动

### 4.5 小金属

**投资逻辑**：
- 稀缺性：储量有限，分布集中
- 需求爆发：新能源、人工智能、军工需求增长
- 供给刚性：开采周期长，短期难以扩产

**重点品种**：

| 金属 | 应用领域 | 需求驱动 | 中国储量占比 | 投资标的 |
|------|---------|---------|-------------|---------|
| 稀土 | 电机、硬盘、军工 | 新能源车、风电 | 30% | 北方稀土、盛和资源 |
| 钴 | 电池正极材料 | 新能源车 | 不足10% | 华友钴业、寒锐钴业 |
| 锆 | 核电、陶瓷 | 核电建设、半导体 | 不足10% | 东方锆业、三祥新材 |
| 钛 | 航空航天、机器人 | 机器人、飞机 | 26% | 宝钛股份、西部材料 |
| 锂 | 电池正极材料 | 新能源车、储能 | 6% | 赣锋锂业、天齐锂业 |
| 锗 | 光纤、红外光学 | 5G、军工 | 35% | 驰宏锌锗、云南锗业 |
| 镓 | 半导体、LED | 5G、新能源 | 80% | 中国铝业、驰宏锌锗 |

**风险提示**：
- 替代材料技术突破
- 需求不及预期
- 地缘政治风险

## 6. 场景脚本库

### 6.1 全球宏观趋势判断

**场景**：需要判断当前全球经济处于什么阶段，未来趋势如何

**推荐流程**：

5. 用 `技术革命分析` 识别新兴机会

**输出物**：宏观趋势分析报告 + 资产配置建议

### 6.2 资产配置方案设计

**推荐流程**：

**输出物**：个性化资产配置方案 + 投资组合

### 6.3 行业投资机会分析

**场景**：想投资某个行业，但不知道如何分析

## 7. 风险提示与避坑指南

### 7.1 投资认知陷阱

| 陷阱 | 表现 | 规避策略 |
|------|------|---------|
| 趋势误判 | 把短期波动当长期趋势 | 用周期理论确认趋势级别 |
| 过度自信 | 过于相信自己的判断 | 建立止损纪律，分散配置 |
| 锚定效应 | 被买入成本左右决策 | 关注未来价值，忽略历史成本 |
| 损失厌恶 | 亏损后死扛，不愿止损 | 设定止损线，机械执行 |
| 从众心理 | 跟风炒作，追涨杀跌 | 独立研究，逆向思考 |
| 过度交易 | 频繁买卖，手续费侵蚀收益 | 降低交易频率，长期持有 |

### 7.2 常见错误

**错误 1：用战术勤奋掩盖战略懒惰**
- 表现：沉迷于技术分析、短线交易，忽视宏观趋势
- 破解：先判断大趋势，再做具体投资

**错误 2：把运气当能力**
- 表现：短期赚钱后过度自信，加大投入
- 破解：用概率思维，区分运气和能力

**错误 3：忽视黑天鹅**
- 表现：只考虑正常情况，不考虑极端情况
- 破解：压力测试，预留安全边际

**错误 4：过度分散**
- 表现：持有几十只股票，精力无法覆盖
- 破解：核心持仓5-10只，卫星持仓10-15只

**错误 5：卖得太早**
- 表现：短期上涨后过早卖出，错过主升浪
- 破解：用趋势跟踪，让利润奔跑

### 7.3 周期误用警示

```
⚠️ 周期理论不是预测工具，而是理解工具
⚠️ 周期长度是统计规律，不是精确计时器
⚠️ 周期嵌套是简化模型，现实更复杂
⚠️ 周期理论在极端情况下可能失效
⚠️ 不要试图精确预测周期拐点，只能模糊识别
```
