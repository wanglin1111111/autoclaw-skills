# system-health-optimization

Agent system health diagnosis and global optimization skill.

## Features
- Cron audit (frequency, errors, delivery, orphaned tasks)
- Approval storm diagnosis (Safety Guard vs Agent orchestration)
- Agent behavior rule injection
- Session zombie process detection

## Usage
Triggered by user complaints of repeated commands, approval spam, or system slowdown.

## Methodology
First-principles based: multi-agent performance issues are typically layered design conflicts, not single bugs.

## Outputs
- Root cause chain analysis
- Before/after comparison table
- Diagnosis report file
